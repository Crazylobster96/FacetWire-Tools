2026-10-05, Windows/Python 3.11 test environment, pinned external FacetWire schema. This is a development candidate, not a published package release. No user document, model or network service was used.

`PackageWorkspace` provides an immutable source inventory and explicit nested definition/instance location. `PackageEditor` now allows two exact-scope operations on that inventory: replace an existing resource's bytes by path and old digest; or change one of the already-supported descriptor fields by exact descriptor path, old descriptor digest, stable object ID and old field value. Both require `definition_all_instances`. References, path set, object identity, media declarations and unsupported fields stay fixed. In particular, shared child definitions cannot be silently edited as only one visible instance.

The workset uses the existing `DraftJournal`, `DescriptorStore` and `ManagedSaves` for durable patch, undo/redo, history, source CAS, dirty reload and unknown-outcome reconciliation. Public `facetwire.package.*` and `facetwire.package_source.*` tool schemas are profile-specific; the original self-contained document tool names and CLI remain unchanged. A managed source save first writes a canonical SQLite workset, not the original `.agscene` directory. A separate host-bound `PackageExport` materializes that saved source into a new immutable version directory, with a source/version/workset manifest, no original overwrite, full file-set reread and original-operation reconciliation. Extra files, links, stale source, changed manifest, changed bytes, limits and failed staging are rejected. Trusted CLI authorization for a **new** export is rechecked before dispatch, staging and visibility; disabling new exports leaves original-operation read-only reconciliation available. Independent Tools itself does not publish to Pillow/Relay or refresh a Renderer.

Independent complete gate: `python tools/test-core.py --facetwire-schema-root <pinned external schema>` passed 179/179 tests, zero skips, 1502/1502 statements and 586/586 branches across every source file, 100% per file. Focused synthetic cases include valid shared nested descriptor edits, invalid scope, stale resource/descriptor hashes, malformed geometry, changed references/object IDs, resource capacity, durable undo/redo/reload, generic AI tool dispatch, real-file new-generation export, tamper detection, provenance, bounds and failure reconciliation. The fixed-path CLI profile is covered, including its separate export enable flag, mid-operation revocation and recovery-read availability when new exports are disabled. Pillow's routed package conversation focused tests passed 5/5 and combined publication/cache/package tests passed 25/25. Parent Pillow Foundation gate and Mac/iPhone native verification have not yet been rerun for this candidate.

Pillow's later in-scope adapter may publish a separately approved, bounded saved workset through Relay, but that is not a capability of this independent Tools project. Remaining for U-07b: dual-end Renderer readback, actual Apple/Windows UI and crash/power-loss validation. Export uses a new generation and never atomically overwrites an existing source directory; an orphan staging directory after abrupt host death needs manual inspection. This record does not claim U-07 or Stage 2 completion.
