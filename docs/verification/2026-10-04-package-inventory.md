# Read-only package workset inventory

2026-10-04 Windows/Python 3.11 local synthetic verification. `PackageWorkspace` reads an explicitly selected, resolved `.agscene` directory and captures bounded, immutable bytes for its root descriptor, recursive document references and resource references. It validates the pinned external FacetWire schema, text profile, exact in-scope paths, references, cycles and limits; digest changes when any captured file changes. No source file is changed and no model or renderer is called.

`python tools/test-core.py --facetwire-schema-root <pinned-external-schema>`: 111/111 tests passed, 1145/1145 statements and 438/438 branches covered across every source file, without exclusions or skips. The ten new synthetic tests cover recursive resources (including a valid zero-byte resource), stable digest, changed bytes, shared references, missing/duplicate/cyclic references, traversal, links, short read, schema/profile invalidity, portable naming and explicit capacities. The final check rejects a source changed during inventory. Core media references, secondary poster/artwork/timed-text files and text font references are checked against declared media types; opaque resources are not decoded or rendered. Nested target lookup distinguishes two visible instances of the same child definition and rejects a result beyond the explicit read cap; it never chooses an edit scope for the caller.

This is only the read-only precursor to U-07b. It does not provide an editing session, transactional history, undo/redo, save/reload, binary media parsing, package export or a host authorization bridge. It has not been built/tested on macOS or Linux in this change.
